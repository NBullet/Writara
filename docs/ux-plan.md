# Writara UI/UX 优化清单

> 2026-10-24。功能已经完善，这一阶段只做外壳与浮层的打磨，不做教学、引导或新手流程。
> 纸面版式与刻度不动（`consistency.test.ts` 守着）；改的是顶栏、侧栏、状态栏、命令面板、对话框、提示层与字体分工。

## 0. 方向

- **常规桌面应用**：布局可预期，控件一眼认得，不靠动效解释自己。
- **安静**：强调色只给当前动作；干净的文档里不应出现第二处红。
- **键盘优先**：每个图标按钮都有 tooltip 与键位，焦点环始终可见。
- **状态唯一**：保存、模式、文件名各只有一个出处。

## 1. 已完成

### 1.1 顶栏与状态栏（2026-10-24）

- `src/components/icons.tsx`：24 视框 / 1.8 描边 / `currentColor` 的 SVG 图标；
  顶栏、侧栏、文件树里的 `⌘ ⚙ ⌕ ⟳ ＋ ✎ ✕` 全部替换。
- 顶栏：文档名居中（窄屏回到动作区左侧），脏标记跟随文件名；动作改为 28px 图标按钮，
  保存按钮只在有未保存修改时变强调色；加动作分隔线。
- 状态栏：视图开关收进一个轻量分段容器；「查找」与模式切换用竖线分开；
  保存状态改成「圆点 + 文字」，有修改时圆点变强调色。
- 焦点：`focus-visible` 统一 2px 强调色环。
- 窄屏：< 760px 隐藏字符数、阅读时间与模式组，只留字数与保存状态；< 640px 给正文让出 14px 边距。

### 1.2 命令面板与侧栏（2026-10-24）

- **命令面板**（`CommandPalette.tsx`）：
  - 结果分四组：最近 / 命令 / 文件 / 标题；组内按匹配分数排序。
  - 匹配：标签子串优先，其次路径与关键词，最后英文子序列；命中的字符用强调色加粗。
  - 最近使用 6 条，存 `localStorage: writara:palette-recent`。
  - 空查询保留菜单顺序；表情符号这类长尾命令只在输入后出现；禁用项不显示。
  - 底部键盘图例；↑↓ 循环选择，Enter 执行，Esc 关闭。
  - 行尾显示菜单路径与快捷键；文件显示所在目录。
- **侧栏**（`Sidebar.tsx`）：
  - 「大纲 / 文件树」改成与状态栏同一套分段样式。
  - 工作区标题 + `+`（新建）+ `⋯`（新建 / 刷新 / 关闭文件夹），去掉常驻的三个文字按钮。
  - 拖动右边缘调宽 200–360px，双击复位；宽度存 `localStorage: writara:sidebar-width`。
  - 文件行铅笔进入内联重命名：Enter 提交、Esc 取消、失焦提交；空名与同名不提交。
  - 重命名当前打开的文件时同步文档身份（`renameIdentity`），避免下一次保存写回旧路径。

### 1.3 确认框与提示层（2026-10-24）

- **确认框**（`ConfirmDialog.tsx` + `confirm.ts`）：应用内多动作对话框，取消 + 1–2 个动作。
  替换了 4 处原生 `confirm`：切换文件（保存并继续 / 放弃 / 取消）、关窗（保存并关闭 / 不保存 / 取消）、
  删除（删除 + 撤销）、覆盖磁盘（覆盖 / 取消）。Esc 与「取消」都返回 null，不会误执行。
- **提示层**（`Toaster.tsx` + `toast.ts`）：固定右下、一次一条；成功 4s 消失、错误常驻；
  撤销 8s；新提示顶掉旧提示，不堆成通知中心。
- **删除撤销**：删除前先读原文，删除后提示层给「撤销」；撤销走
  `WorkspaceController.restoreFile`（桌面端新增 `fs:restoreFile` IPC，浏览器端按相对路径逐级重建）。
  删的是当前打开的文件时，先切回未命名文档，撤销后再打开恢复的文件。
- **不再挤动正文**：提示条改成 `position: fixed` 的堆叠层；导出完成改成提示层，不再常驻横幅。

### 1.4 字体（2026-10-24）

用户反馈正文字体「有锯齿感」。检查结果：

- 正文此前是衬线栈，Windows 上落到 Noto Serif SC；17px / 1x 下宋体的细横线在灰度抗锯齿里会发虚。
- `body` 上有一条全局 `-webkit-font-smoothing: antialiased`，在 Windows 上会关掉亚像素抗锯齿，
  正文更薄、更毛。已删除。
- 字体分工改为：**正文无衬线，标题衬线**。
  - `--wr-font-prose`：`Segoe UI` / `PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`，屏幕阅读优先。
  - `--wr-font-heading`：Iowan / 思源宋体 / Noto Serif SC / Songti / Georgia。
  - 编辑器标题、打印/导出的 `h1–h6` 都引用 `--wr-font-heading`；导出时由 `theme-vars.ts` 内联。
  - 主题同步：GitHub / Night / Whitey 的标题跟正文一起用无衬线；Newsprint / Pixyll 保留全衬线。
- 新增一条一致性测试，确保编辑器与打印的正文、标题字体引用同一个变量。

### 1.5 交互反馈（2026-10-24）

此前外壳只有两处动效：Toast 入场 160ms、按钮 hover 120ms；其余菜单、面板、对话框都是硬切。
这一轮补齐常用交互，全部只动 `transform` / `opacity`，不参与布局：

- 菜单 / 右键菜单：100ms 上浮 + 淡入；子菜单 100ms 位移 + 淡入。
- 命令面板：遮罩 120ms 淡入，面板 140ms 上浮 + 0.985→1 缩放；结果行 hover 90ms。
- 侧栏「大纲 / 文件树」：160ms 滑动药丸（`--tab-index` 驱动 thumb）。
- 对话框：140ms 上浮 + 0.98→1；遮罩 120ms 淡入。
- 提示条：140ms 从上落下；Toast 进场 160ms、退场 140ms。
- 文件树 / 大纲 / 状态栏模式：90–120ms 颜色过渡。
- `prefers-reduced-motion: reduce` 下全部关闭。

### 1.6 滚动条与快捷键弹窗（2026-10-24）

- **滚动条**：外壳统一成 10px 细滚动条，透明轨道、圆角滑块、悬停加深；
  只使用 `::-webkit-scrollbar`（Chromium / Electron），Firefox 才走 `scrollbar-width` 回退。
  两者不能同时写：只要指定标准 `scrollbar-width`，Chromium 就会忽略 WebKit 样式，
  又回到带上下箭头的系统滚动条。已逐个检查：大纲、文件树、命令面板、偏好设置左右栏、
  快捷键弹窗、搜索列表、关于页；CodeMirror 仍走自绘滚动条。
- **快捷键弹窗**：从一条长列表改成「头 + 搜索 + 两列分组 + 底部」：
  - 每组一张浅色卡片，行内按键拆成独立 `kbd` 键帽，不再挤成一串文字。
  - 顶部搜索框按功能名或键位过滤，无结果时给空状态。
  - 头部用品牌 W，关于页改成单张说明卡；底部固定 `Esc` 提示与关闭按钮。
  - 窄屏 < 640px 自动落成单列，弹窗高度 86vh，正文自身滚动。

验证：`typecheck` / `lint` / 342 项测试 / `build` 通过；1440、375 两档与明暗主题都检查过。
命令面板的最近、标题分组、子串高亮；确认框、提示层、快捷键弹窗与滚动条都手工走过
（真实删除流程需要在桌面端文件夹里点一次）。

## 2. 设置、导出与窄屏（2026-10-25 已完成）

- **偏好设置**：
  - 开关换成真 switch（`role="switch"` + 轨道），单选换成 segmented（`:has(input:focus-visible)` 保键盘焦点环）。
  - 主题改成卡片网格：6 个主题各带一张纸面缩略图（背景/文字/标题衬线/强调色/链接），选中项描边用主题强调色。
    缩略图取色单独放在 `settings/theme-preview.ts`——`[data-style]` 只挂在 `:root`，嵌套拿不到变量。
  - 每个分区标题右侧「恢复默认」，只重置本节绑定到字段的条目；`customCss` 不重置（用户内容）。
  - 底部按钮语义定为**完成即生效**（左侧写明「设置即时生效 · Esc 关闭」），不做草稿回滚：
    主题、字号、栏宽需要即时预览，草稿模式会让「预览」与「已保存」两套状态互相打架。
- **导出**：浏览器顶栏新增「导出」菜单（PDF / HTML / PNG / Word / ePub）。
  Pandoc 不可用时 Word / ePub 置灰并在行尾写「需要 Pandoc」，另给「去设置 Pandoc 路径…」；
  命令仍然走同一批 `export-*` 命令 id，进度与完成提示由既有提示层负责。桌面端顶栏不渲染，
  导出仍在原生「文件」菜单里（同一批 id、同样的置灰规则）。
- **空状态**：命令面板无结果显示「没有找到「…」」+ 搜索建议 + 「查看全部命令」；
  文件夹搜索区分「还没打开文件夹」「没搜到」「还没输入」三种情况，各给下一步。
- **窄屏**（≤760px）：侧栏改成抽屉（遮罩 + 160ms 滑入，宽 320px，打开后点条目/遮罩自动收起）；
  顶栏动作收进 `⋯`（命令面板 / 查找 / 导出 / 保存 / 偏好设置）；状态栏保持单行（≤640px 只留「侧栏」开关）。
  第一次进入窄屏或窄屏启动时侧栏默认收起。

## 4. 视觉规范（新增组件照这个来）

| 项 | 值 |
| --- | --- |
| 网格 | 4px；控件高度 28 / 32 / 36 |
| 图标 | 16px，1.8 描边，`currentColor`，24 视框 |
| UI 字号 | 12.5–13px；正文不动 |
| 圆角 | 控件 6px，面板 8–12px，分段 7px |
| 边框 | 1px `var(--wr-border)`；不叠加阴影做层次 |
| 动效 | 120–160ms，只解释因果；尊重 `prefers-reduced-motion` |
| 强调色 | 只给当前动作、脏标记与选中态 |

## 5. 验收

- 1440 / 1024 / 760 / 375 四档：无横向滚动、无换行错位的状态栏、无死控件。
- 明暗两套主题：图标、边框、悬停、选中态都从 `--wr-*` 取色，没有写死颜色。
- 键盘：Tab 能到每个图标按钮；焦点环可见；对话框 Esc 关闭、Enter 提交。
- 字体：正文无衬线、标题衬线；编辑器与 PDF 引用同一组变量；不再有 `-webkit-font-smoothing`。
- 命令面板：输入三个字符能到任意命令；最近记录在重开后仍在。
- 侧栏：拖动后宽度在重开后保留；内联重命名 Esc 不落盘。

## 6. 不做

- 不做营销页式的渐变、玻璃、大插画。
- 不给纸面加常驻格式工具栏；格式入口留在菜单、命令面板、右键。
- 不为「看起来现代」改排版 token；屏幕与 PDF 的一致性测试守着这条线。
- 不在桌面端隐藏菜单后又不给键盘入口。
