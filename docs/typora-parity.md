## 1. Typora 的能力面

### 1.1 编辑与渲染

- **Hybrid View**（官方）：源码与渲染同层，光标离开后隐藏标记；行内与块级元素都参与。
- **源代码模式**：一键回到纯文本，用于排查格式问题。
- **专注模式 / 打字机模式**：前者让非当前行变淡，后者让当前行固定在屏幕中央（常见绑定 F8 / F9）。
- **自动配对、智能标点、列表/引用/代码块自动续写、Tab 缩进、拖拽移动块**。
- 撤销 / 重做、多光标、查找替换（正则、全词、选区内）。

### 1.2 Markdown 语法（官方 Markdown Reference 目录）

| 类别 | 条目 |
| --- | --- |
| 块级 | 段落与换行（软换行 / 硬换行）、ATX 与 Setext 标题、引用、有序 / 无序列表（嵌套）、任务列表、围栏代码块（语言高亮）、数学公式块、表格、脚注、水平线、YAML Front Matter、目录 `[TOC]`、图表（sequence / flowchart / mermaid） |
| 行内 | 链接（内联 / 参考 / 内部锚点）、裸 URL、图片、斜体、粗体、行内代码、删除线、下划线、emoji `:smile:`、行内数学 `$…$`、下标 `~x~`、上标 `^x^`、高亮 `==x==` |
| HTML | 内嵌 HTML、视频、自定义样式 |

### 1.3 文件与导航

- 侧边栏两部分：**大纲**（按标题层级，可点击跳转）、**文件树 / 文件列表**。
- 文件操作：新建、重命名、删除、拖拽移动、在资源管理器中显示、复制路径、刷新。
- **快速打开**（Windows `Ctrl+P`）模糊搜索当前文件夹。
- **全局搜索**（`Ctrl+Shift+F`），支持标签 `#tag` 检索。
- 最近文件 / 文件夹；启动时恢复上次会话；链接到本地文件 `file.md#anchor`。

### 1.4 图片

- 语法插入、拖拽、粘贴（含网络图片落地到本地）、一次拖入多张。
- 插入时复制到 `./${filename}.assets` 或指定目录，可强制相对路径；YAML `typora-copy-images-to`。
- 图床上传（PicGo / iPic / uPic / 自定义命令）。
- 图片路径后可挂标签作为 CSS 钩子；尺寸控制（Markdown 扩展与 HTML `<img width>`）。

### 1.5 导出与打印

- 原生：**PDF / HTML / HTML（无样式）/ 图片**。
- 经 Pandoc：Word (.docx)、RTF、ePub、LaTeX、MediaWiki、Textile、OpenOffice、reST、OPML。
- PDF 导出设置（官方）：纸张、主题、分页、页眉页脚、PDF 元数据、追加自定义内容（如封面）。
- 导入（经 Pandoc）：docx、latex/tex、rst、org、wiki、textile、opml、epub。

### 1.6 外观与设置

- 主题：内置多套 + 自定义 CSS；系统暗色。
- 偏好设置：编辑器（字体、行宽）、Markdown（严格模式、自动配对、智能标点）、图片、导出、快捷键、拼写检查、默认换行符。
- 状态栏：字数、行数、当前文件。

## 3. 已确认的问题（bug）

### 3.1 数据安全（最该先修）

> P0 已修：1–4 全部处理，见第 6 节。以下保留为问题记录。

1. **`Ctrl+S` 不写回原文件**：`downloadMarkdown` 只是触发下载，浏览器会把副本放进下载目录；
   文件被打开后并没有保存通道，句柄用完即丢。
2. **没有脏标记、没有关页提醒**：改完直接关标签页，文件仍是旧内容，用户以为已保存。
3. **文件身份丢失**：重开浏览器只能恢复「最后一段文本」；草稿还可能与用户之后打开的文件互相覆盖。
4. **IME 组合期没有保护**：装饰在每次 `docChanged` 重建，中文输入法候选阶段可能被打断或闪烁。

### 3.2 与 Typora 的核心体验差异

5. 表格在编辑器里是源码（Typora 是可视化表格，可加行/列、改对齐）。
6. 图片在编辑器里不显示。
7. 链接不可点击（Typora 里 `Ctrl/Cmd+Click` 打开）。
8. 打印/导出的代码块没有语法高亮，与编辑器不一致。
9. 光标所在行会露出**整行**所有标记，Typora 只展开光标附近的那一个元素。
   ~~（2026-10-23 已修：改为按被触到的 span 展开，见 [focus-views.md](./focus-views.md)）~~

> 逐块编辑态（哪种块聚焦时该给什么视图：表格工具条、公式源码 + ✓、图表预览面板、图片展开、代码围栏折叠）
> 的调研与落地方案见 [focus-views.md](./focus-views.md)。

### 3.3 可用性

10. `Ctrl+P` 被打印占用，和 Typora 的「快速打开」冲突（需要重新分配，并在文档里写清楚）。
11. `?print=1` 只能看草稿，不能选文件，也没有返回编辑器的入口。
12. 长文档每次按键都做一次全文 `<svg` 扫描（`svgBlocks`），大文件会掉帧。
13. 打印预览只能靠 URL 参数发现，界面里没有入口。
14. 没有错误提示：文件读写失败、图片加载失败都是静默的。

### 3.4 细节

15. 导出 HTML 的 `<title>` 取首个标题，文件名却取 md 文件名，二者不一致。
16. 代码块缺少语言标签 / 复制按钮。
17. 打开文件会清空撤销历史（Typora 会保留一轮）。
18. ~~编辑器与打印的字号/行宽不同（42rem vs 174mm）~~：已修，打印按 `--wr-measure` 排栏宽，纸张放不下时整篇等比缩字号，换行位置与屏幕一致。

## 4. 浏览器能力边界

| 能力 | 现实约束 | 结论 |
| --- | --- | --- |
| 文件读写 | File System Access API 仅 Chromium；Safari / Firefox 只能下载副本 | Chromium 优先，其他浏览器降级为「下载」并明确提示 |
| PDF 页码 / 页眉页脚 / 书签 | 浏览器打印不暴露这些设置；页码只能在打印对话框里勾选 | 能做的：纸张 / 页边距 / 主题；书签需要自建 PDF 生成，先不做 |
| docx / epub / LaTeX 导出 | 不能调用 Pandoc；Word 的样式由参考模板决定 | docx/ePub 走「Markdown → Pandoc + `--reference-doc`」，模板随包；LaTeX 仍未做 |
| 图片复制到 `assets/` | 需要目录写权限（Chromium） | 可做，但只在 Chromium 下提供 |
| 多窗口 | PWA 是多标签页 | 用标签页 + 会话恢复替代 |
| 全局搜索 / 文件树 | 需要目录权限 | 可做（Chromium） |

## 5. 优先级结论

1. **先把「写的东西不会丢」做对**：文件写回、脏标记、关闭提醒、IME 安全。这四项之前，其他功能都没有意义。
2. **再补 Typora 的渲染差异**：表格、图片、链接、脚注/TOC，让编辑器和打印说同一种语言。
3. **然后是写作体验**：大纲、专注/打字机、查找替换。
4. **最后才是学术能力与文件管理**：公式、图表、文件夹工作区、导出增强。

执行清单见项目计划面板（`Writara × Typora 对齐路线`）。

## 6. 进度

### P0 已完成（2026-10-21）

- 文件写回：`Ctrl+S` 通过 File System Access 写回原文件；`Ctrl+Shift+S` 另存为；
  没有 API 的浏览器降级为下载，并在提示条说明。
- 覆盖保护：保存前读磁盘比对，被外部修改时先确认。
- 脏标记：标题 `●`、状态栏「未保存」、关闭页面拦截。
- 会话恢复：句柄存 IndexedDB；重开时按「草稿 vs 磁盘」决策恢复，冲突只提示不覆盖。
- IME：组合输入期间不重建装饰。
- 设置：主题（跟随系统/浅色/深色）、字号、栏宽、草稿延迟，实时生效并持久化。
- 错误提示：文件权限、文件丢失、磁盘空间等翻成中文提示条。

测试：82 个用例通过（新增 settings / file-system / restore 三组）。

### P1 已完成（2026-10-21）

- **排版基准**（2026-10-23）：取 GitHub Markdown CSS 的标题阶梯与间距关系，统一收进
  `src/styles/tokens.css` 的 `--wr-*` 变量，编辑器与打印/导出只引用这一组。
  中文只改了两处：行高 1.7、段间距等于源码里的一行空行。标题不再叠加 `padding-top`，
  间距一律按正文字号折算——屏幕与纸面同版式。
- **预览与 PDF 一致性**（2026-10-23）：打印不再缩字号，只缩栏宽（A4 常规 16mm ≈ 672px = 默认栏宽）；
  高亮/链接/代码/上下标的字形与颜色、列表符号（• ◦ ▪）、任务方框字体、emoji 全部两边对齐，
  并由 `src/styles/consistency.test.ts` 逐项守住；PDF 预览窗口按 100% 打开。
- 表格在编辑器里渲染成真表格并**常驻渲染态**：单击单元格就地编辑（浮层输入，回车提交），
  表头上方有工具条（对齐 / 增删行列 / 删表）；只有搜索跳转等程序化选区才会退回源码。
  对齐、行内标记都生效。
- **右键菜单**（2026-10-23）：文件树（打开 / 打开所在文件夹 / 复制路径 / 复制相对路径 / 重命名 / 删除；
  文件夹与空白处另有对应项）、编辑器（剪切 / 复制 / 粘贴 / 复制为 Markdown·HTML·纯文本 / 全选 / 查找）、
  以及光标在表格里时的「表格」子菜单：上方或下方插入行、左右插入列、删除本行/本列/整表、
  列对齐（左/中/右/默认）、格式化表格、编辑表格源码。表格操作改写的是 Markdown 源码，不是 DOM。
- **文件树**（2026-10-23）：文件夹可折叠（点击整行切换）、文件/文件夹图标、当前文档高亮并自动
  展开所在目录、滚入视野、筛选时强制全部展开；工具条改成「＋ 新建 / ⟳ 刷新 / ✕ 关闭」。
- **分块编辑态 P2**：表格 Tab/Shift+Tab 连跳（末格 Tab 加行）、图片选中浮条（25/50/75/100% /
  原始 / 复制路径）、HTML 块渲染（`<details>` 跨空行会接回一段）。
- 图片：`http(s)` / `data:` / `blob:` 显示为 `<img>`，非法协议与加载失败退化为占位。
- 链接：`Ctrl/Cmd + Click` 打开；`#锚点` 跳到对应标题；导出 HTML 的标题带 `id`（同名加序号）。
- `[TOC]`：编辑器里是可点击目录，打印/导出生成带锚点的目录块。
- Front Matter：不进入导出，编辑器里以元信息样式显示；`title:` 可作为文档标题。
- 链接引用定义（`[ref]: url`）：导出不输出，编辑器里按元信息弱化显示（不隐藏——隐藏后会留一整行空行，
  前后两个空行叠成一个明显的洞）。
- 无序列表的 `-` / `*` / `+` 显示成圆点，与打印/导出一致。
- 打印/导出的代码块有语法高亮（highlight.js 按需加载，主题色与正文统一）。

### 编辑增强（2026-10-24）

- **定义列表**：`术语` 下一行起写 `: 解释`（可多条）。渲染成 `<dl>/<dt>/<dd>`；
  编辑器里术语加粗、解释缩进 1.6em，非编辑态隐藏行首 `: `。判定在 `markdown/deflist.ts`，
  编辑器（`analyze.ts`）与打印（`render.ts`）共用，`consistency.test.ts` 守住字重与缩进。
- **公式自动编号**：「偏好设置 → Markdown → 公式 → 自动编号」。按文档顺序给块级公式补 `\tag{n}`，
  自己写了 `\tag` 的公式保持原样且不占号；编辑器与打印用同一套规则（`markdown/math-number.ts`）。
- **表格列宽拖拽**：表头每格右边界是拖拽手柄（`table-blocks.ts`）。拖拽期间只改 `<col>` 像素宽度，
  松手才把比例写回分隔行的横线数（`| --- | ------- |`）——这是唯一不需要私有元数据的存法；
  打印按同一份比例输出 `<colgroup>` + `table-layout: fixed`。
- **图片拖拽缩放**：图片右下角手柄，松手写成 `=宽`（`markdown/image-size.ts` 的 `withImageWidth`）。
  有 `title` 的图片不给手柄：尺寸语法与 `"title"` 互斥。
- **公式交叉引用**：`\label{名字}` 起名，`$\eqref{名字}$` 渲染成 `(n)`、`$\ref{名字}$` 渲染成 `n`；
  支持前向引用，找不到的标签显示 `??`。引用写在数学模式里（与 Typora 一致），正文里的裸 `\eqref` 不处理。
  编号规则见 `markdown/math-number.ts` 的 `scanMath()`，编辑器与打印共用。
- **文件编码**：桌面端读文件时按 BOM → 严格 UTF-8 → GB18030 判定，保存写回原编码与 BOM；
  状态栏出现编码标签（如 `GB18030`），或「文件 → 以 UTF-8 重新保存」一次性迁移。
  浏览器端仍只有 UTF-8（`TextEncoder` 不能编码 GBK）。

### 已知差距

- **打印端的语言覆盖**：编辑器接入 CodeMirror 语言包（98 种），打印/导出用 highlight.js 完整构建，
  覆盖其中 92 种（`asm` 映射到 `x86asm`）；ABAP / Apex / CSV / Mermaid / Solidity / Vue 仍是单色
  （Mermaid 走自己的渲染）。
- **定义列表的边界**：只认顶层段落；列表项、引用块里的定义列表按普通段落显示（两边一致，不会一边认一边不认）。
  一个术语后接多行定义可以，多术语共用一个定义（`Term1` / `Term2` + `: 定义`）不支持。
- **公式编号**：只有按文档顺序的自动编号，没有按章节编号；交叉引用已支持（`\label` / `\eqref` / `\ref`）。
- 表格列宽用分隔行的横线数编码，直接改源码的人要明白「横线数量 = 相对宽度」。
- 单独打开的 `.md` 文件需要先在「文件 → 设置图片根目录…」里选一次文件夹，才能解析相对路径图片。
- 多标签页、云同步未做；Word / ePub 导出走 Pandoc（需自行安装），PDF 页码与书签已由 `printToPDF` 生成。
- 不支持导入 Word / ePub / LaTeX；没有图床（图片上传）；没有版本历史 / 自动备份。
- 编码：桌面端支持 UTF-8 / UTF-16 / GB18030；其它编码（Big5、Shift-JIS 等）会按 GB18030 解，可能是乱码。
  浏览器端只有 UTF-8。
- 界面只有中文；快捷键固定，不能自定义。
- 「新建窗口」只是再开一扇窗，会话与草稿仍共用一份；mac / linux 的打包目标配了但没验证（mac 还需签名 / 公证）。
- 导出的 HTML 里 Mermaid 已经是静态 SVG；图片若是工作区相对路径，会内联成 data URL，文件会变大。
